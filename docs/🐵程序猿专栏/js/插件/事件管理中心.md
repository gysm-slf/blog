# 事件管理中心

## 介绍

- 支持单一事件接收返回值
- 同一类型支持注册若干事件，且支持按优先级顺序执行
- 支持一次性事件
- 支持链式注册与移除
- 支持事件行为独占（isRefresh：true 保证注册事件后仅存在该行为）

::: warning 注意
当在 `vue` 中反过来使用时，如在子组件中注册，在父组件中触发，此时需要注意组件的加载时机，否则可能导致首次触发无效
:::

::: danger 与 `vue.$emit` 的最大区别
1. $emit 触发事件一对一，一个组件的若干个实例发起事件时会发到父组件中各自的监听中，而

   EventManagementCenter.emit 触发时，父组件内无法区分触发的子组件实例，需要自行添加 `key` 进行区分。
:::

## 新特性✨

* 事件注册逻辑优化，当函数体完全相同时重复注册仅会生效一次 <Badge type="tip" text="^2026-07-01" />
* `remove` 支持传入正则来移除符合命名的所有事件，注册时可使用命名空间方式，对事件进行分类管理 <Badge type="tip" text="^2026-07-10" />

> 正则移除演示

```js
EventManagementCenter.regist('ai.conversation.input', () => {})
EventManagementCenter.regist('ai.conversation.keyup', () => {})
EventManagementCenter.regist('ai.conversation.focus', () => {})
EventManagementCenter.emit('ai.conversation.focus')
EventManagementCenter.remove(/^ai\.conversation/) // 所有 ai.conversation 被全部移除
```

## 源码

::: code-group

```js [event-management-center]
import { jsonProcessor } from './json-processor'

/**
 * 文档地址：http://192.168.20.187:8888/🐵程序猿专栏/js/插件/事件管理中心.html#介绍
 * @author: slf
 * @date: 2024/12/19 16:09
 */
export const EventManagementCenter = (function () {
  const events = {}
  return {
    // type: 事件名称 fn: 事件处理器  isRefresh:是否刷新(注册事件时会把之前注册过的同名事件先清空,如果出现组件内切换导致重复注册了事件可打开此选项)
    regist: function (type, fn, isRefresh = false, { priority = 0 } = {}) { // 订阅某个事件
      fn = typeof fn === 'function' ? fn : () => {}
      fn.priority = priority
      if (typeof events[type] === 'undefined' || isRefresh) {
        events[type] = [fn]
      } else {
        if (events[type].map(f => jsonProcessor.stringify(f)).indexOf(jsonProcessor.stringify(fn)) === -1) {
          events[type].push(fn)
        }
      }
      return this
    },
    emit: function (type) { // 向订阅者发送信息
      if (!events[type] || events[type].length === 0) return
      if (events[type].length === 1) return events[type][0].call(this, ...(Array.from(arguments).slice(1)))
      events[type].sort((a, b) => b.priority - a.priority)
      let cacheLen = events[type].length
      for (let i = 0; i < events[type].length; i++) { // 注意，当某事件需要多处订阅时，不支持返回注册的函数结果 因为无法保证与识别对应顺序 也不要调整存储结构增加复杂性 一般不建议使用emit的返回值 即使是支持该功能的时候 如果需要接收多返回值 建议使用不同事件名称，最终效果是一致的
        events[type][i].call(this, ...(Array.from(arguments).slice(1)))
        if (cacheLen > events[type].length) { // 发生触发后即时销毁事件(即在一个类型事件调用期间,发生了部分事件取消订阅) 依旧从原索引处任务开始
          i--
          cacheLen = events[type].length
        }
      }
    },
    remove: function (type, fn) {
       if (type instanceof RegExp) {
          Object.keys(events).forEach((eK) => type.test(eK) && delete events[eK])
       } else {
          const list = events[type] || []
          if (list.length === 0) return this
          if (typeof fn === 'function') {
             for (let i = list.length - 1; i >= 0; i--) {
                if (list[i] === fn) list.splice(i, 1)
             }
          } else {
             delete events[type]
          }
       }
      return this
    }
  }
})()
```

```js [json-processor]
const FUNC_PREFIX = 'FUNC_PREFIX'
let isEnabledLog = false

export const jsonProcessor = {
  stringify: function (obj, space) {
    try {
      return JSON.stringify(obj, (k, v) => typeof v === 'function' ? `${FUNC_PREFIX}${v}` : v, space)
    } catch (err) {
      if (isEnabledLog) {
        console.warn(err)
      }
    }
  },
  parse: function (jsonStr = '""') {
    try {
      return JSON.parse(jsonStr, (key, value) => typeof value === 'string' && value.indexOf(FUNC_PREFIX) > -1 ? new Function(`return ${value.replace(FUNC_PREFIX, '')}`)() : value)
    } catch (err) {
      if (isEnabledLog) {
        console.warn(err)
      }
    }
  },
  copy (obj = {}) {
    return this.parse(this.stringify(obj))
  },
  enableLogging () {
    isEnabledLog = true
  }
}
```

## 参数文档

### regist

| 参数名            |            说明            | 类型 | 默认值 |
|----------------|:------------------------:|:------:|:------:|
| type           |           事件名称           | string | — |
| fn             | 行为函数，当有事件触发时，激活事件下对应所有行为 | function | — |
| isRefresh      |  是否独占，开启则注册时会移除已存在的其它行为  | boolean | false |
| \{ priority \} | 优先级，同一事件下行为，数值越高越执行顺序越靠前 | number | 0 |

### emit

| 参数名 | 说明 | 类型 | 默认值 |
|---------------|:-------------:|:------:|:------:|
| type | 触发的事件名称 | string | — |

### remove

| 参数名 |   说明    | 类型 | 默认值 |
|---------------|:-------:|:------:|:------:|
| type | 移除的事件名称 | string | — |
