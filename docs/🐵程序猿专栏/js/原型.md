# 原型

## 核心概念

### 函数原型（`prototype`）
- 函数特有的属性，用来给实例提供共享方法（箭头函数、`bind` 生成的函数除外）。
- 当函数作为构造函数（通过 `new` 调用）时，新创建的对象会**内部链接**到该函数的 `prototype` 对象。
- 构造函数本身的 `prototype` 对象包含一个 `constructor` 属性，指向构造函数自身。

```javascript
function Person(name) {
  this.name = name;
}
console.log(Person.prototype.constructor === Person); // true
```

**本质：**
一个普通对象，用于存放共享属性和方法，用于构建通过 `new` 创建的实例的 `__proto__`。

### 对象原型（`__proto__`）
- 是每个对象都有的属性，默认情况下，`__proto__` 指向构造函数的 `prototype` ，构成原型链。
- 函数也对象，所以同时拥有 `prototype` 和 `__proto__`

**本质：**
一个访问器属性，指向对象的**实际原型**，实例的 `__proto__` 指向其构造函数的 `prototype`。

## 原型链（Prototype Chain）

```js
// 1. Object 的构造来源
Object.__proto__ === Function.prototype  // true，Object 是函数，是 Function 的实例

// 2. Function 的构造来源
Function.__proto__ === Function.prototype  // true，Function 也是自己的实例

// 3. Function.prototype 的原型
Function.prototype.__proto__ === Object.prototype  // true，函数原型对象继承自对象原型

// 4. Object.prototype 的终点
Object.prototype.__proto__ === null  // true
```

## `instanceof` 运算符

### 原理
`obj instanceof FnDemo` 判断 `FnDemo.prototype` 是否出现在 `obj` 的原型链上。

### 特殊情况

```javascript
function Parent() {}
const child = new Parent();

console.log(child instanceof Parent);   // true
console.log(child instanceof Object);   // true (Parent.prototype 最终继承自 Object.prototype)
console.log([] instanceof Array);       // true
console.log([] instanceof Object);      // true

// 改变原型链后
function Another() {}
Object.setPrototypeOf(child, Another.prototype);
console.log(child instanceof Parent);   // false
```

## 常用示例

```js
// 假设已有构造函数和原型方法
function Person(name) {
  this.name = name;
}
Person.prototype.sayHello = function() {
  console.log('Hello');
};

// 批量添加多个属性/方法，不影响原有 sayHello
Object.assign(Person.prototype, {
  eat() {
    console.log(`${this.name} is eating`);
  },
  sleep() {
    console.log(`${this.name} is sleeping`);
  },
  walk() {
    console.log(`${this.name} is walking`);
  },
  // 也可以加普通属性
  species: 'human'
});

// 测试
const p = new Person('Tom');
p.sayHello(); // Hello
p.eat();      // Tom is eating
console.log(p.species); // human
```

::: danger 提示
不要 `Person.prototype = {}` 这样做，会丢失原有的 sayHello 方法和 prototype 中的 constructor
:::

## 类（class）与原型的关系
- ES6 `class` 本质是语法糖，底层仍是原型和构造函数。

```javascript
class Animal {
  speak() {}
}
class Dog extends Animal {}
const d = new Dog();
console.log(d.__proto__ === Dog.prototype);          // true
console.log(Dog.prototype.__proto__ === Animal.prototype); // true prototype 本身是一个对象，对象的.__proto__本应该指向 Object.prototype 但这里使用 ES6 extends 方式继承改变了原型链（内部实现可能是使用了类似的Object.create） 
console.log(d instanceof Dog);                       // true
console.log(d instanceof Animal);                    // true
```

## 注意点

### 不要直接修改 `__proto__`
- 非标准属性，性能差。使用 `Object.setPrototypeOf` 或 `Object.create`。

### 函数的 `prototype.constructor` 可能被覆盖

```javascript
function Foo() {}
Foo.prototype = { bar: 1 }; // 丢失 constructor
const f = new Foo();
console.log(f.constructor === Foo); // false
// 建议手动恢复
Foo.prototype.constructor = Foo;
```
