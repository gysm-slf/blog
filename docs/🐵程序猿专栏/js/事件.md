# 事件

## this

当为 `dom` 绑定的函数为匿名函数时，`this` 为触发事件的 `dom` 对象。

```js
document.querySelector('.test').onclick = function () { 
  console.log(this) 
}
```

## 生命周期

冒泡阶段调用
默认情况下，使用 addEventListener 添加的事件监听器是在冒泡阶段被调用的。这意味着当事件开始从目标元素向上冒泡时，这些监听器将依次被触发，从最深层的元素开始，一直到最外层的元素。
目标阶段：事件到达目标元素，如果目标元素上有监听器，它们会被触发。
捕获阶段调用
如果你在添加事件监听器时，将第三个参数（capture）设置为 true，那么这个监听器将在捕获阶段被调用。这意味着在事件到达目标元素之前，这些监听器将从最外层的元素开始，依次被触发，直到到达目标元素。
document和body均为冒泡阶段事件(绑定事件不指定参数默认就为冒泡)

```html
<div class="root click">  
  <div class="second-1 capture-click">  
    <div class="third-1 no-click-event"></div>  
    <div class="third-2"></div>  
  </div>  
  <div class="second-2"></div>  
</div>
```

当点击third-1时，触发顺序为
捕获阶段 second-1 -> third-1
目标阶段 third-1(即使没有绑定事件实际上不会影响顺序)
冒泡阶段 third-1 -> root -> body -> document
常用属性
target: 表示事件最初触发的 DOM 元素。这是事件的起点。
currentTarget: 表示当前正在处理事件的元素，这可能是 target 或者是某个祖先元素，取决于事件流。
keyCode, charCode: 分别表示键盘事件中的按键代码和字符代码。
button: 表示触发事件的鼠标按钮（0 = 左键，1 = 中间，2 = 右键）。
eventPhase: 数字，表示事件处于哪个阶段：1 - 捕获阶段，2 - 目标阶段，3 - 冒泡阶段。
cancelable: 布尔值，表示事件是否可以被取消。

常用方法
stopPropagation(): 阻止事件继续向上冒泡。
preventDefault(): 阻止事件的默认行为。
