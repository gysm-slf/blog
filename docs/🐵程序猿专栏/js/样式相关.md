# 样式相关

## height、offsetHeight、clientHeight、scrollHeight

- **`height`**：CSS 属性（如 `element.style.height`）或 `getComputedStyle` 返回的字符串值（如 `"100px"`），需注意单位，且可能为 `auto`。它仅表示元素的内容高度（受 `box-sizing` 影响），不包含滚动条、边框等。

- **`offsetHeight`**：只读整数，表示元素的**布局高度**，包含元素内容、内边距（`padding`）、滚动条（若存在）和边框（`border`），不包括外边距（`margin`）。计算公式：`offsetHeight = height + padding + border + scrollbar`（若滚动条存在且占用空间）。适用于获取元素实际占用的可视区域高度。

- **`clientHeight`**：只读整数，表示元素的**内部可视区域高度**，包含内边距（`padding`），但不包含边框、滚动条和外边距。对于有滚动条的元素，`clientHeight` 等于滚动条内部视口的高度（即 `content + padding`，减去滚动条宽度）。可用于计算可滚动内容的容器高度。

- **`scrollHeight`**：只读整数，表示元素的**内容总高度**（包括不可见部分），包含内边距（`padding`），但不包含边框、滚动条和外边距。如果内容超出容器，`scrollHeight` 大于 `clientHeight`，其差值即为可滚动的距离。适用于判断是否需要滚动条或计算滚动位置。

| 属性 | 包含内容 | 包含边框 | 包含滚动条 | 包含外边距 | 只读 |
|------|----------|----------|------------|------------|------|
| `offsetHeight` | 内容 + padding + border | 是 | 是（占用空间） | 否 | 是 |
| `clientHeight` | 内容 + padding | 否 | 否（减去滚动条宽度） | 否 | 是 |
| `scrollHeight` | 内容 + padding（包括溢出部分） | 否 | 否 | 否 | 是 |
| `height` | 取决于 CSS，通常为内容高度 | 否（除非 `box-sizing: border-box`） | 否 | 否 | 否（可读写） |
