# 文献综述

[figma 原型](https://www.figma.com/design/LU2cDhhJgUiGurQfKpSnIT/CNKI-AI?node-id=2-1159&p=f&t=RMdml5F3R9ymHWTH-0)

## 流程参考

```txt
0 输入内容

1 开始思考，拆解问题。【类似于深度研究的问答页和思考过程】

1.1 修改【加入用户编辑的修改意见】
1.2 重新生成【无用户意见直接重新生成】
1.3 同意，进入下一步。

【思考中…
我们将根据生成的主题创建一个完整的、可重复的检索策略，由模型先生成检索子问题、多轮扩写、综合
召回高质量、高相关文献。】

2 选择文献 【知网文献+用户资源】
2.1 重新生成【策略待确认】
2.2 同意，进入下一步，展示已选文献列表，文献列表可编辑
2.3 生成文献综述提纲
2.3.1 怎么生成的
【一段提示词->模型【huazhi_mix】->生成这么一大坨 Markdown 带层级关系】
生成大纲的提示词和文献综述专业版保持一致：【提示词抠出来】

3 生成提纲
3.1 替换，针对编辑后的结果替换初始状态内容
3.2 放弃，放弃已编辑的内容，恢复初始状态
3.3 编辑，点编辑提纲激活编辑窗口
3.4 重新生成，无用户干预直接重新生成
3.5 生成全文->4

思考中...
我们将根据选择的文献范围，及生成的文献综述提纲由模型确定：
进10年以来的文献，生成文献发文趋势
最新发文、奠基行论文、过聚类研究主题、作者、机构、期刊合作网络、跨学科联系维度生成研究主题的趋势判断、新兴热点和衰落主题
按照提纲生成规范生成文献综述全文

4 综述报告全文
4.1 工具栏：复制、导出、智能研读、辅助创作
4.2 报告正文
4.2.1 正文内引文角标[参考来源]，悬停显示详细信息
4.3 参考文献
4.3.1 原文段落【是当前报告所有依据的选中文献的片段】
4.3.2 相似段落【只有选中某一个片段的情况下才进行相似片段的推荐，当未选中状态下无法选择相似段落，相似段落置灰】
4.3.2.1 相似段落中点击应用按钮重新生成相应正文内容
4.3.2.2 相似段落最多10个
4.3.3 参考文献可以收起可以展开
4.3.4 参考文献可以分页
```
